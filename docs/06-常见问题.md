# 常见问题

## 部署与启动

**后台启动后访问报错，日志里数据库调用卡住十几秒后失败**

容器型云托管不会自动注入腾讯云凭证，必须手工配 `TENCENTCLOUD_SECRETID` 和
`TENCENTCLOUD_SECRETKEY`。这是最常见的首次部署问题。

**每次重新部署后都要重新登录**

没配 `TOKEN_SECRET`。不配时代码用的是随机值，进程一重启就变，已签发的令牌全部失效。
配一个固定的长随机字符串即可。

**后台能登录，但图片管理、缩略图、孤儿图扫描都报错**

没配 `COS_BUCKET`。代码里的桶名推断逻辑对你的环境是错的，必须显式配置。
桶名在 CloudBase 控制台云存储页面可以直接看到。

**小程序里图片全部裂开**

CloudBase 默认存储域名会强制浏览器下载而不是显示，所以后台缩略图走的是同源代理。
小程序端则需要 CDN 域名配置正确，见[品牌替换清单](04-品牌替换清单.md)。

## 支付

**用户付款成功，但订单一直是待支付**

回调地址不对。`cloudfunctions/pay/index.js` 里的回调地址必须是你自己的
云托管服务域名加 `/payNotify`，而且这个地址要能被微信服务器公网访问到。

必须用真机真单验证，开发者工具的模拟支付不会触发回调。

**支付时报商户号或签名错误**

检查云函数的支付环境变量。特别注意商户私钥要填整段 PEM 文本，
包含开头和结尾的标记行，换行不能丢。

## 功能行为

**商品显示售罄但我明明上架了**

多规格商品的库存是各规格库存之和。所有规格库存都为零时整体显示售罄。
售罄和下架是两回事，售罄的商品仍然在列表里可见。

**批量操作跑到一半失败，返回一堆 HTML**

云托管网关有 60 秒超时。批量重压图片这类长任务本身是分批设计的，
如果自己新增长任务接口，要按同样的方式分批加续跑参数。

**AI 助手不回话**

没配 `AI_GATEWAY_BASE_URL` 和 `AI_GATEWAY_API_KEY` 时，接口仍然正常响应，
但第一帧返回的是未配置提示。配上任意 OpenAI 兼容的网关即可。

助手的写操作（发货、设置分销员）需要二次确认，模型会先问你再执行，这是有意设计的。

## 二次开发

**后台前端是一个八千多行的 HTML 文件**

是的。`admin/public/index.html` 包含了后台的全部界面。这是历史形成的，
不是推荐做法。好在它按功能分区排列，搜索区块注释或功能名能快速定位。

拆分它是一件独立的、有回归风险的工程，目前没有做。

**我新增了一个图片字段，结果旧图被当成孤儿删掉了**

孤儿图扫描依据的是一份引用字段清单。新增任何存图片的字段，
必须同步更新 `admin/routes/storage.js` 里的两处收集逻辑，
以及 `admin/routes/products.js` 里保存商品时的引用计数检查。

三处漏一处就会误判。这个坑真实发生过，后果是图片被物理删除且不可恢复。

**小程序富文本里的样式不生效**

小程序的 `rich-text` 只认内联样式，不认 CSS 类，外部样式表也穿透不进去。
编辑器已经配置成输出内联样式，但如果你自己拼 HTML，要注意这一点。

另外 `rich-text` 里的图片是普通 img 而不是 image 组件，
挂不了长按识别，这是组件本身的能力边界。

**我直接改了 admin/ 或 miniprogram/ 里的文件，下次同步没了**

这两个目录是从上游仓库生成的，会被覆盖。改动请通过 issue 或 pull request 提出，
见[贡献指南](../CONTRIBUTING.md)。
