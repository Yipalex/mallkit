# 快速开始

从零把 Mallkit 跑起来。按顺序做，跳步会卡住。

整个过程大概半天到一天，其中大部分时间在等微信和腾讯云的审核，不是在写代码。

---

## 开始之前

你需要先有这些，缺一不可：

- **微信小程序账号**。个人主体也能注册，但**个人主体开不了微信支付**。要收款必须是企业、个体工商户或其他组织主体。
- **腾讯云账号**，并开通一个 CloudBase 环境。按量计费即可起步。
- **微信支付商户号**，如果要收款。需要小程序认证通过后再申请，审核一般几个工作日。
- 本机装好 Node.js 20 或更高版本、微信开发者工具、Git。

如果只是想先看看效果，不收款，可以跳过商户号，后面支付相关的步骤一并跳过。

---

## 第一步：准备云环境

在[腾讯云 CloudBase 控制台](https://console.cloud.tencent.com/tcb)创建环境，
计费模式选按量计费。创建后记下：

- **环境 ID**，形如 `your-env-abc123`
- **存储桶名**，在云存储页面能看到，形如 `abcd-你的环境id-你的腾讯云APPID`
- **所在地域**，如 `ap-shanghai`

这三个值后面到处要用，先记在手边。

然后在[访问管理](https://console.cloud.tencent.com/cam/capi)创建一对 API 密钥，
记下 SecretId 和 SecretKey。SecretKey 只在创建时显示一次。

> 这对密钥等同于你腾讯云账号的操作权限。只填进 CloudBase 控制台的环境变量，
> 不要写进代码、不要提交进 Git、不要发在聊天工具里。

---

## 第二步：创建数据库集合

在控制台的数据库页面建这些集合。空集合即可，结构由代码写入时决定。

```
users            orders           products         categories
carts            coupons          user_coupons     reviews
banners          popups           settings         system_config
point_logs       exchange_logs    gifts            error_logs
distributors     distributor_invites               commission_logs
withdrawals      refund_requests  recharge_logs
enterprises      enterprise_logs  voucher_batches  voucher_codes
```

权限统一设成**仅管理端可读写**。小程序端的数据访问全部经过云函数，
不需要给客户端直接读写权限，给了反而是风险。

建完后加两个索引：

- `voucher_codes` 集合的 `code` 字段，**唯一索引**。这个是强制的，不加会出现重复券码。
- `voucher_codes` 集合的 `batchId` 和 `enterpriseId`，普通索引，加了查询快很多。

---

## 第三步：部署云函数

用微信开发者工具打开本仓库的 `miniprogram/` 目录。

先在 `project.config.json` 里把 `appid` 改成你自己的小程序 AppID，
再在 `miniprogram/app.js` 里把环境 id 改成你的。

然后在 `cloudfunctions/` 目录上右键，逐个上传部署这些函数：

```
user      product   cart      order     pay       payNotify
member    gift      popup     voucher   distribution   orderTimeout
```

部署完在 CloudBase 控制台给支付相关的函数配环境变量，
清单见[配置项参考](05-配置项参考.md)。不收款可以先不配。

`orderTimeout` 需要定时触发器，用来自动取消超时未支付的订单。
在控制台给它配一个每 5 分钟执行一次的触发器。

---

## 第四步：部署管理后台

后台部署到 CloudBase 云托管，源码在 `admin/`。

在控制台新建一个云托管服务，上传 `admin/` 目录，然后配置环境变量。
最少要配这五个才能启动：

```
TCB_ENV                 你的环境 id
TENCENTCLOUD_SECRETID   第一步创建的 SecretId
TENCENTCLOUD_SECRETKEY  对应的 SecretKey
ADMIN_PASSWORD          你自己设的后台登录密码
TOKEN_SECRET            一串长随机字符串
```

另外建议同时配上 `COS_BUCKET` 和 `COS_REGION`，不配的话图片管理功能用不了。
完整清单见[配置项参考](05-配置项参考.md)。

部署完访问服务域名，应该能看到登录页。用 `admin` 和你设的密码登录。

> 登录后第一件事：在「账号安全」里改掉密码并绑定两步验证。
> 后台有商品、订单和用户数据的完整权限。

---

## 第五步：填店铺信息

登录后台，进「店铺设置」，填店名、客服电话、地址、营业时间、运费规则。
这些填完，小程序端的对应位置立即就有了，不需要改代码。

再进「商品管理」建几个分类和商品，传几张图，好让小程序端有东西显示。

---

## 第六步：跑通小程序

回到微信开发者工具，编译预览。

检查这几件事：

1. 首页能加载出商品，图片能正常显示。
2. 商品详情页能打开，能加入购物车。
3. 能进入结算页，地址选择正常。
4. 「我的」页面能正常登录，显示昵称头像。

图片显示不出来，通常是 CDN 域名没改对，见[品牌替换清单](04-品牌替换清单.md)。

---

## 第七步：验证支付

**这一步必须用真机和真实订单**，一分钱就行。开发者工具的模拟支付不会触发回调，
回调地址配错在模拟环境里发现不了，上线后表现为用户付了钱但订单不变成已支付。

先确认 `cloudfunctions/pay/index.js` 里的回调地址填的是你自己的云托管域名加 `/payNotify`。

然后真机下单支付，支付完检查：

- 订单状态变成已支付
- 后台订单列表能看到这笔单
- 库存扣减正确
- 如果配了企业微信群机器人，群里收到推送

四项都对，支付链路就通了。
