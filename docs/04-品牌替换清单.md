# 品牌替换清单

换成你自己的品牌，分两类工作：**在后台页面上填的**，和**必须改代码的**。
先做第一类，能覆盖绝大部分可见内容；第二类只有几处，主要是主题色。

---

## 一、在后台填就行（不用改代码）

登录管理后台，进「店铺设置」，填这些：

- 店铺名称。小程序首页、分享卡片、支付账单、后台标题都会用到。
- 客服电话、店铺地址、营业时间。
- 运费规则、包邮门槛、自提点信息。
- 商品详情页的服务承诺文案。
- 商品海报上的文案（顶部标语、底部标语、角标、价格标签）。

进「分销设置」填佣金比例。这些改完保存，小程序端立即生效。

---

## 二、必须改代码的部分

### 1. 基础配置（不改就跑不起来）

| 文件 | 位置 | 占位值 |
|---|---|---|
| `miniprogram/project.config.json` | `appid` | `touristappid` |
| `miniprogram/miniprogram/app.js` | `wx.cloud.init` 的环境 id | 占位环境 id |
| `miniprogram/cloudfunctions/order/index.js` | AppID 常量 | `touristappid` |
| `miniprogram/cloudfunctions/pay/index.js` | AppID 常量、支付回调地址 | `touristappid` |
| `miniprogram/miniprogram/pages/product/detail.js` | 图片 CDN 域名 | 占位域名 |
| `miniprogram/cloudfunctions/product/index.js` | 图片 CDN 域名 | 占位域名 |

CDN 域名和存储桶名在 CloudBase 控制台的云存储页面能查到。
支付回调地址是你的云托管服务域名加上 `/payNotify`。

### 2. Logo 与图标

| 文件 | 说明 |
|---|---|
| `miniprogram/miniprogram/assets/logo-brush.png` | 小程序 logo。直接替换同名文件，尺寸接近即可。 |
| `miniprogram/miniprogram/assets/icons/` | 底部导航栏图标，各一组常态与选中态。是通用图形，不换也不违和。 |

后台的 logo 和站点图标从店铺设置里读，上传即可，不用改文件。

### 3. 主题色

小程序的配色集中在 `miniprogram/miniprogram/app.wxss` 顶部的 `page` 选择器里，
改那几个变量就能整体换肤。默认是绿色系。

| 变量 | 默认值 | 作用 |
|---|---|---|
| `--color-primary` | `#5CAE52` | 主色，按钮、选中态、强调 |
| `--color-primary-light` | `#6FC363` | 主色浅版 |
| `--color-primary-dark` | `#4A9A42` | 主色深版 |
| `--color-primary-bg` | `#EAF6E5` | 主色浅底，标签和图标背景 |
| `--color-ink` | `#243426` | 主文字与深色按钮底 |
| `--color-accent` | `#E8963F` | 价格与促销高亮 |
| `--color-bg` | `#F8FBF6` | 页面背景 |

改完这几个，绝大部分界面就跟着变了。

**另有三处用不了 CSS 变量，必须单独改**，因为它们在 JSON 和组件属性里：

| 位置 | 字段 | 默认值 |
|---|---|---|
| `miniprogram/miniprogram/app.json` | `window.navigationBarBackgroundColor`、`window.backgroundColor` | `#F8FBF6` |
| `miniprogram/miniprogram/app.json` | `tabBar.color`、`tabBar.selectedColor` | `#9FB0A1` / `#5CAE52` |
| `miniprogram/miniprogram/pages/index/index.wxml` | 轮播图 `indicator-active-color` | `#6FC363` |

漏改这三处的症状是：页面内容已经换成新色，但顶部导航栏、底部标签栏或轮播小圆点还是绿的。

后台的配色写在 `admin/public/index.html` 的 Tailwind 配置段，用的是 emerald 色系。
搜索 `emerald` 就能找到全部出现位置。

### 4. 用户协议与隐私政策

`miniprogram/miniprogram/pages/terms/terms.wxml` 和 `pages/privacy/privacy.wxml`
里是通用模板文案，提到店铺的地方写的是「本商城」。

上线前请按你的实际经营范围和主体信息重写，这是合规要求，不是可选项。
如果你卖的是特殊品类（食品、生鲜、酒类等），条款需要相应调整。

---

## 三、改完怎么验证

1. 微信开发者工具打开 `miniprogram/`，编译无报错。
2. 首页、商品详情、下单页、我的，四个页面看一遍，确认没有残留的占位文案和颜色。
3. 真机预览，重点看导航栏和标签栏的颜色是否统一。
4. 用一笔一分钱的真实订单走通下单、支付、回调、发货全流程。

支付链路必须用真机真单验证。开发者工具的模拟支付不覆盖回调，回调配错在模拟环境里看不出来。
