# 配置项参考

分三层：后台环境变量、云函数环境变量、数据库里的店铺设置。
改店名、电话、运费这类经营信息属于第三层，在后台页面上改，不用碰代码。

---

## 一、管理后台环境变量

在 CloudBase 控制台的云托管服务里配置。改完需要重新部署才生效。

### 必填

| 变量 | 说明 |
|---|---|
| `TCB_ENV` | CloudBase 环境 id。控制台首页可见。 |
| `TENCENTCLOUD_SECRETID` | 腾讯云 API 密钥 SecretId，在[访问管理](https://console.cloud.tencent.com/cam/capi)创建。 |
| `TENCENTCLOUD_SECRETKEY` | 对应的 SecretKey。 |
| `ADMIN_PASSWORD` | 后台登录密码。**没有默认值，不配就无法登录**，这是刻意的。 |
| `TOKEN_SECRET` | 登录令牌签名密钥，随便一串长随机字符串。**不配会在每次重启后掉登录态**，因为回退值是随机生成的。 |

容器型云托管不会自动注入腾讯云凭证，必须手工配这两个密钥，
否则数据库调用会卡住十几秒后失败。

### 云存储相关

| 变量 | 说明 |
|---|---|
| `COS_BUCKET` | 存储桶名。**强烈建议显式配置**，见下方说明。 |
| `COS_REGION` | 存储桶地域，默认 `ap-shanghai`。环境不在上海的必须改。 |

代码里桶名有一个推断逻辑，会用内置的哈希前缀和 APPID 拼装，那对你的环境是错的。
桶名在 CloudBase 控制台的云存储页面可以直接看到，照抄过来配上即可。
不配的后果是云存储管理、图片缩略图、孤儿图扫描都不可用。

### 微信相关

| 变量 | 说明 |
|---|---|
| `WX_APPID` | 小程序 AppID。用于生成小程序码（分销码、礼券码）。 |
| `WX_APPSECRET` | 小程序密钥。 |
| `WX_MCH_ID` | 微信支付商户号。仅退款功能需要。 |
| `WX_MCH_SERIAL_NO` | 商户 API 证书序列号。 |
| `WX_MCH_PRIVATE_KEY` | 商户 API 私钥内容。**整段 PEM 文本，包含首尾的标记行**，换行保留。 |
| `WX_QRCODE_ENV` | 生成小程序码时指定的版本，可选。 |

### 可选

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | `80` | 监听端口。云托管默认 80，不要改。 |
| `ADMIN_USERNAME` | `admin` | 登录用户名。 |
| `ADMIN_TOTP_SECRET` | 无 | 两步验证密钥。在后台页面绑定后由系统写入，一般不手工配。 |
| `AI_GATEWAY_BASE_URL` | 无 | AI 助手的模型网关地址，OpenAI 兼容格式。 |
| `AI_GATEWAY_API_KEY` | 无 | 网关密钥。 |
| `AI_GATEWAY_MODEL` | 见代码 | 模型名。 |
| `ASSISTANT_MAX_TOOL_ROUNDS` | `3` | AI 助手单轮对话最多调用几轮工具。 |
| `ASSISTANT_TIMEOUT_MS` | `55000` | 助手软超时。**不要调到 60 秒以上**，云托管网关有 60 秒硬限制。 |

不配 AI 网关时助手界面仍然可用，只是第一帧会返回一条未配置的提示。

## 二、云函数环境变量

在 CloudBase 控制台按函数配置。只有支付和登录相关的函数需要。

| 变量 | 用在哪 | 说明 |
|---|---|---|
| `WX_MCH_ID` | pay, payNotify | 商户号 |
| `WX_API_V3_KEY` | pay, payNotify | APIv3 密钥，用于回调验签和解密 |
| `WX_MCH_SERIAL_NO` | pay | 商户证书序列号 |
| `WX_MCH_PRIVATE_KEY` | pay | 商户私钥 PEM 全文 |
| `WX_PAY_PUBLIC_KEY_ID` | pay | 微信支付公钥 id |
| `WX_APPSECRET` | user | 小程序密钥，登录换取用户标识用 |
| `WEWORK_WEBHOOK_URL` | payNotify | 企业微信群机器人地址。配了就在新订单时往群里推送，不配就跳过。 |

支付凭证只存在于环境变量里，代码和仓库中没有任何一份副本。

### 代码里需要手工改的地方

云函数里有两个值目前是字面量，不走环境变量：

| 位置 | 内容 |
|---|---|
| `cloudfunctions/order/index.js`、`cloudfunctions/pay/index.js` | 小程序 AppID，占位值是 `touristappid` |
| `cloudfunctions/pay/index.js` | 支付回调地址，需要填你自己环境的云托管域名加 `/payNotify` |

小程序端另有两处：`miniprogram/app.js` 里的环境 id，和
`miniprogram/pages/product/detail.js` 里的图片 CDN 域名。
详见[品牌替换清单](04-品牌替换清单.md)。

## 三、店铺设置（数据库）

存在 `settings` 集合的 `store` 文档里，在后台「店铺设置」页面上改，
改完小程序端立即生效，不需要重新部署。

| 字段 | 含义 |
|---|---|
| `storeName` | 店铺名称 |
| `phone` | 客服电话 |
| `address` | 店铺地址 |
| `openTime` / `closeTime` | 营业时间 |
| `shippingFee` | 默认运费 |
| `freeShippingThreshold` | 包邮门槛 |
| `shippingRules` | 分地区运费规则 |
| `pickupAddress` / `pickupPhone` / `pickupNote` | 自提点信息 |
| `serviceLabel` / `serviceText` / `serviceVisible` | 商品详情页的服务承诺 |
| `posterTopSlogan` / `posterBottomSlogan` / `posterBadgeText` / `posterPriceLabel` | 商品分享海报上的文案 |

分销佣金比例存在同一集合的另一条文档里，在后台「分销设置」改。

> 给二次开发者：新增设置字段时，除了写入逻辑，还要把字段名加进
> `admin/routes/settings.js` 的更新白名单，否则字段会被静默丢弃。
