# 截图目录

README 里引用的截图放这里。文件名必须和下表一致，否则 README 里的图显示不出来。

## 需要的文件

### 小程序端（8 张）

| 文件名 | 截哪个页面 |
|---|---|
| `miniprogram-home.png` | 首页，要能看到轮播图和商品列表 |
| `miniprogram-detail.png` | 商品详情页，最好选一个有多规格的商品 |
| `miniprogram-cart.png` | 购物车，里面放 2 到 3 件商品 |
| `miniprogram-my.png` | 「我的」页面 |
| `miniprogram-checkout.png` | 结算页，能看到地址、运费、优惠券 |
| `miniprogram-orders.png` | 订单列表，最好有几个不同状态的订单 |
| `miniprogram-member.png` | 会员中心，能看到等级和积分 |
| `miniprogram-distribution.png` | 分销中心 |

## 截图前先做这件事

**把截图里的真实经营数据处理掉。** 这是公开仓库，截图一旦推上去就是公开的，
删掉也会留在 git 历史里。

具体要检查：

- 真实的店铺名称、logo、slogan
- 客户姓名、手机号、收货地址（订单和用户页面最容易漏）
- 真实的营业额、订单量、佣金金额
- 商品名称如果能反推出你卖什么品类，也建议换成通用商品
- 后台顶栏、浏览器标签页、地址栏里的域名
- 微信昵称和头像

最省事的做法是**先把品牌改成占位值、灌一批假数据，再截图**。
在真实后台上截图然后逐个打码，很容易漏掉一处。

用打码的话，用不透明色块盖住，不要用马赛克或高斯模糊，那两种有被还原的可能。

## 尺寸与格式

- 格式统一用 PNG
- 小程序截图用手机真机截图即可，竖屏，宽度 750 到 1200 像素比较合适
- 后台截图建议浏览器窗口调到 1440 宽左右再截，太宽在表格里会被压得看不清
- 单张控制在 500 KB 以内。文件太大会让 clone 变慢，也会占仓库空间
- 图片多的话可以用 `pngquant` 或 `tinypng` 压一下，肉眼看不出差别
