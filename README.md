# Mallkit

A WeChat Mini Program storefront with a Node.js admin backend, running on
Tencent CloudBase. It is a working shop, not a scaffold: orders, WeChat Pay,
SKUs, coupons, distribution, points, corporate vouchers and an AI operations
assistant are all wired up and in production use.

Mallkit is brand-neutral by construction. Every shop name, phone number,
address and environment id in this repository is a placeholder, and the setup
guide walks through replacing them.

## What you get

**Mini program** — 27 pages: home, category and search, product detail with
multi-spec SKUs, cart, checkout with WeChat Pay, order tracking with logistics,
member tiers, points and check-in, coupons, a distribution centre for
referrers, corporate voucher redemption by QR code, and account settings.

**Admin backend** — an Express server with dashboard, products and categories,
orders with shipping and refunds, users and points, customer analytics,
distributors and commission settings, coupons and reviews, corporate voucher
accounts and batch QR generation, monthly finance with CSV export, cloud
storage management, and a built-in AI assistant that answers questions about
the shop and performs a small set of guarded write operations.

**Cloud functions** — 12 functions covering orders, payment and payment
callbacks, cart, user and login, distribution, membership, gifts, popups,
vouchers, and an order-timeout sweeper.

## Requirements

- A Tencent CloudBase environment, pay-as-you-go or a paid plan
- A WeChat Mini Program account, with WeChat Pay if you want to take payments
- Node.js 20 or newer for the admin backend
- WeChat Developer Tools for the mini program

The admin backend is designed for CloudBase Cloud Run and needs Node 20,
because image processing uses sharp 0.35.

## Getting started

Read [docs/01-快速开始.md](docs/01-快速开始.md). It covers the whole path from a
fresh clone to a running shop, in the order you actually need to do things.
Setup takes a few hours, most of it waiting on WeChat and Tencent approvals.

The short version:

1. Create a CloudBase environment and note its id.
2. Fill in `miniprogram/project.config.json` with your mini program AppID.
3. Deploy the cloud functions and create the database collections.
4. Deploy the admin backend to Cloud Run with the environment variables from
   [docs/05-配置项参考.md](docs/05-配置项参考.md).
5. Open the admin backend, set your shop name and contact details, and upload a
   logo. Most branding is read from the database, so you will not be editing
   code for it.
6. Work through [docs/04-品牌替换清单.md](docs/04-品牌替换清单.md) for the handful
   of things that genuinely need a code change, such as theme colours.

## Repository layout

```
admin/          Express admin backend, deployed to CloudBase Cloud Run
miniprogram/    WeChat Mini Program and its cloud functions
docs/           Setup, configuration and customization guides
tools/sync/     Mirrors this repository from its upstream; see below
```

`admin/` and `miniprogram/` are generated by the sync tool from a private
upstream repository where development happens. Edits made directly to those
directories will be overwritten on the next sync. To propose a change, open an
issue or a pull request and it will be applied upstream; see
[CONTRIBUTING.md](CONTRIBUTING.md).
